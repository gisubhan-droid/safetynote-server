## 1. 권한(역할) 구조 한눈에 보기

SafetyNOTE는 **3단계 권한 구조** + **LGU+ 별도 권한**으로 운영됩니다.

| 화면 표시 역할 | DB 권한 그룹 | 메뉴 그룹 수 | 사용 가능 범위 |
|---------------|-------------|------------|----------------|
| **CEO** | 관리자 (admin) | 5그룹 | 전체 메뉴 + 시스템 설정 + 계정관리 + 단가 관리 |
| **시스템관리자** | 관리자 (admin) | 5그룹 | CEO와 동일 |
| **안전관리자** | 감독자 (supervisor) | 5그룹 | 전체 메뉴 + 시스템 설정 (계정·단가 제외) |
| **공무** | 감독자 (supervisor) | 5그룹 | 안전관리자와 동일 |
| **현장대리인** | 감독자 (supervisor) | 5그룹 | 안전관리자와 동일 |
| **근로자** | 근로자 (worker) | 3그룹 | 내 작업 / 위험신고 / 서명요청 / 내 계정만 |
| **LGU+** | lgu_plus | 별도 설정 | 관리자가 그룹별 권한 설정 탭에서 지정한 메뉴만 |

> **아이콘 색상 안내**
> 👑 관리자 `#D70072`(핑크) | 🔷 감독자 `#685182`(보라) | 🦺 근로자 `#A8005A`(다크핑크)

### 권한 구조 다이어그램

```
DB role: admin
  ├─ CEO          → 5그룹 전체 메뉴 + 계정관리 + 단가관리
  └─ 시스템관리자  → CEO와 동일

DB role: supervisor
  ├─ 안전관리자   → 5그룹 전체 메뉴 (계정·단가 제외)
  ├─ 공무         → 안전관리자와 동일
  └─ 현장대리인   → 안전관리자와 동일

DB role: worker
  └─ 근로자       → 3그룹 (내작업 / 안전 / 내정보)

DB role: lgu_plus
  └─ LGU+         → 관리자 설정에 따른 별도 제한 메뉴
```

## 2. 공통 — 앱 설치 및 첫 로그인

### 2-1. APK 설치 (Android)

1. 로그인 화면 하단 **"APK 설치 파일 다운로드"** 버튼을 누릅니다.
   _(버튼이 없으면 관리자에게 APK URL 등록을 요청하세요)_
2. 다운로드된 `.apk` 파일을 실행합니다.
3. **"알 수 없는 출처 앱 허용"** 메시지가 나오면 **허용**을 누릅니다.
4. 설치 완료 후 SafetyNOTE 아이콘을 탭합니다.

> **버전 확인**: 앱 실행 후 로그인 화면 하단에 현재 APK 버전이 표시됩니다.

### 2-2. 브라우저 접속 (PC · 태블릿)

| 환경 | 접속 방법 |
|------|----------|
| 사내 네트워크 | `https://NAS주소:3443` |
| 외부 (DDNS) | `https://도메인:3443` |
| 모바일 브라우저 | 위와 동일 주소 입력 |

> ⚠️ **주의**: 접속 시 인증서 경고가 나오면 **"계속 진행"** 또는 **"고급 → 접속"**을 누르세요.
> (자체서명 인증서 환경인 경우 정상입니다)

### 2-3. 첫 로그인

1. 관리자에게 받은 **아이디(전화번호 형식)** 와 **임시 비밀번호**를 입력합니다.
2. **로그인** 버튼을 누릅니다.
3. 첫 로그인 후 즉시 **내 계정 → 비밀번호 변경**을 진행하세요.

### 2-4. 로그인 화면 구성

```
┌─────────────────────────────────┐
│         SafetyNOTE              │
│                                 │
│   [아이디 입력 (전화번호)]       │
│   [비밀번호 입력]                │
│                                 │
│         [로그인]                 │
│                                 │
│   APK 설치 파일 다운로드 ↓       │  ← 관리자가 APK URL 설정 시 표시
└─────────────────────────────────┘
```

## 3. 공통 — 화면 구성 및 내비게이션

### 3-1. 전체 화면 구조

```
┌──────────────────────────────────────────────────────┐
│  상단 헤더: 현재 페이지 제목 + 알림 아이콘             │
├──────┬───────────────────────────────────────────────┤
│      │                                               │
│ 왼쪽 │              메인 콘텐츠 영역                  │
│ 레일 │                                               │
│(아이 │                                               │
│콘 모 │                                               │
│음)   │                                               │
│      │                                               │
├──────┴───────────────────────────────────────────────┤
│   하단 탭바 (주요 메뉴 바로가기, 모바일 전용)          │
└──────────────────────────────────────────────────────┘
```

### 3-2. 왼쪽 레일 (아이콘 모음)

- 화면 왼쪽에 **그룹 아이콘**이 세로로 나열됩니다.
- 아이콘을 누르면 **플라이아웃 메뉴**(오른쪽으로 펼쳐짐)가 열립니다.
- 플라이아웃에서 원하는 메뉴 항목을 누르면 해당 페이지로 이동합니다.

### 3-3. 권한별 메뉴 그룹 비교

**관리자 · 감독자** (5개 그룹):

| 그룹 아이콘 | 그룹명 | 주요 메뉴 |
|------------|--------|----------|
| 🔵 현장 헬멧 | **현장작업** | 작업현황 · 작업관리 · 공사현황 · 현장위치 지도 |
| 🔴 방패 | **안전점검** | 현장점검 · 위험신고 · 위험성평가 (정기/수시/항목관리/안전설정) |
| 🟣 체크보드 | **안전관리** | 안전현황 통계 · 안전교육 (5종) · 서명요청 |
| 🟢 차트 | **공사현황** | 공사통계 · 작업통계 · 물량통계 · 작업일보 · 공량내역 · 광케이블 현황 |
| 🟡 톱니바퀴 | **관리/설정** | 사용자관리 · 내 계정 · 시스템 설정 · 법령안내 관리 |

**근로자** (3개 그룹):

| 그룹 아이콘 | 그룹명 | 주요 메뉴 |
|------------|--------|----------|
| 🔵 체크리스트 | **내 작업** | 내 작업 · 작업일보 작성 · 나의작업현황 |
| 🔴 방패 | **안전** | 위험신고 · 서명요청 |
| 🟡 톱니바퀴 | **내 정보** | 내 계정 |

### 3-4. 알림 (서명요청)

- 상단 헤더의 🔔 **알림 아이콘**에 빨간 배지가 뜨면 서명 요청이 있습니다.
- 알림 아이콘을 누르면 **서명요청** 페이지로 바로 이동합니다.
- FCM(Firebase Cloud Messaging) 푸시 알림도 동시에 발송됩니다.

## 4. 관리자 (CEO · 시스템관리자) 전용 가이드

> **대상**: DB 권한 `admin` — CEO · 시스템관리자
> **특징**: 전체 메뉴 접근 가능 + 시스템 설정 8개 탭 전체 + 계정관리 + 단가 관리

### 4-1. 사용자 계정 관리

**경로**: 관리/설정 → 사용자관리 → **계정관리** _(시스템관리자만 보임)_

| 작업 | 방법 |
|------|------|
| 신규 계정 등록 | [+ 사용자 추가] 버튼 → 이름·전화번호·역할·직위 입력 → 저장 |
| 비밀번호 초기화 | 해당 계정 행 선택 → [비밀번호 초기화] → 임시 비밀번호 전달 |
| 계정 정지 | 해당 계정 행 → [업무 중지] → 중지 사유 입력 |
| 중지 계정 복구 | 사용자관리 → [업무중지사용자] 탭 → [업무 복구] |
| 역할 변경 | 계정 편집 모달 → 역할 드롭다운에서 변경 |

**역할 드롭다운 옵션:**

```
근로자 / 안전관리자 / 공무 / 현장대리인 / CEO / LGU+ / 시스템관리자
```

**계정 상태 흐름:**
```
신규 등록 → 활성(업무중) → 업무중지 → 업무복구 → 활성
                                       ↑ 관리자만 가능
```

### 4-2. 현장팀 관리

**경로**: 관리/설정 → 사용자관리 → **현장팀관리**

- **팀 생성**: [+ 팀 추가] → 팀명 입력 → 팀원 배정
- **팀원 추가**: 팀 행 선택 → [팀원 추가] → 근로자 검색 후 선택
- **팀 해산**: 팀 행 → [삭제] _(팀원 전원 자동 해제됨)_

> 💡 서명 요청 발송 시 팀 단위로 일괄 선택할 수 있습니다.

### 4-3. 공사 · 작업 전체 관리

**경로**: 현장작업 → **공사현황**

| 상태 흐름 | 설명 |
|-----------|------|
| 등록 | 공사 정보 입력 (공사명 · 공사요청번호 · 현장주소 등) |
| 진행중 | 작업 배정 후 자동 전환 |
| 완료 | 모든 작업 완료 시 수동 완료 처리 |

**작업 배정 방법:**
1. 공사현황에서 해당 공사 선택
2. **[작업 추가]** 버튼 → 작업명·날짜·근로자 배정
3. 근로자 앱에 즉시 반영됨

### 4-4. 단가 관리 _(admin 전용)_

**경로**: 공사현황 → **단가 관리**

- 작업 유형별 단가 등록 및 수정
- 공량내역 / 물량통계의 금액 계산 기준이 됨
- 근로자에게는 금액이 표시되지 않음 (admin/supervisor에게만 노출)

```
단가 등록 방법:
① 단가 관리 탭 → [+ 단가 추가]
② 작업유형 선택 (드롭다운)
③ 단가(원) 입력
④ [저장]

→ 공량내역 페이지에서 자동으로 금액 계산됨
```

### 4-5. 시스템 설정 (8개 탭 전체 상세)

**경로**: 관리/설정 → **시스템 설정**

#### 📢 탭 1 — 푸시 알림 발송

전체 사용자 또는 특정 그룹/개인에게 즉시 알림을 보냅니다.

```
발송 대상 선택:
  ① 전체 발송 — 모든 사용자에게 동시 발송
  ② 그룹 발송 — 현장팀 단위로 선택
  ③ 개인 발송 — 사용자 검색 후 선택

메시지 입력 → [발송] 버튼 클릭
→ FCM을 통해 Android 앱으로 즉시 전달
→ 앱 내 알림 배지 동시 생성
```

> ⚠️ 수신자가 앱 알림 권한을 허용한 경우에만 푸시 알림이 수신됩니다.

```
주요 정보:

파일 목록:
- 최근 업로드된 파일 목록 조회
- 파일 유형별 필터링 (사진 / APK / 기타)
- 개별 파일 삭제 (저장공간 관리)
```

#### 📍 탭 3 — GPS 주소 변환

카카오 API 연동으로 GPS 좌표를 한국어 주소로 자동 변환합니다.

```
초기 설정 방법 (1회):
① 카카오 개발자 콘솔(developers.kakao.com)에서 앱 생성
② REST API 키 복사
③ GPS 주소변환 탭 → [카카오 API 키] 입력란에 붙여넣기
④ [저장] 클릭
⑤ [테스트] 버튼으로 API 작동 확인

설정 후 효과:
- 작업 시작/완료 시 GPS 좌표 → 주소 자동 변환
- 현장점검 위치 자동 주소 표시
- 위험신고 위치 자동 주소 표시
```

> 💡 카카오 API 무료 할당량: 월 30만 건 (일반 현장 규모에서 충분)

#### 🤖 탭 4 — APK 배포 관리

Android 앱 설치 파일(APK)을 등록하고 배포합니다.

```
방법 A — URL 등록 (GitHub Releases 링크):
① [APK URL] 입력란에 다운로드 주소 붙여넣기
   예: https://github.com/gisubhan-droid/safetynote-android/releases/download/v2.0.0/app-release.apk
② [APK 설정 저장] 클릭
③ 로그인 화면 하단 "APK 설치 파일 다운로드" 버튼 생성 확인

방법 B — 직접 업로드 (서버에 파일 저장):
① [파일 선택] → .apk 파일 선택
② [업로드] 버튼 클릭 (서버 /public/uploads/apk/ 에 저장)
③ 업로드 완료 후 자동으로 URL 설정됨
④ [APK 설정 저장] 클릭
```

> 💡 APK 버전 업데이트 시 새 파일로 교체 후 저장하면 됩니다.
> 기존 설치된 앱은 로그인 후 업데이트 안내 팝업이 표시됩니다.

#### 🔄 탭 5 — 서버 업데이트

SSH 없이 브라우저에서 서버를 최신 버전으로 업데이트합니다.

```
① [현재 버전 확인] 버튼 클릭
   → 현재 커밋 해시 vs GitHub main 브랜치 최신 커밋 비교
   → 업데이트 버전 있으면 "N개의 새 커밋이 있습니다" 표시

② [업데이트 적용] 버튼 클릭
   → 실시간 로그 출력:
      [1/4] git fetch origin
      [2/4] git reset --hard origin/main
      [3/4] npm install (필요 시)
      [4/4] PM2 재시작 → patchSchema 자동 적용
   → "업데이트 완료" 메시지 → 30초 후 자동 재접속

롤백:
③ [이전 버전 목록] 탭 → 커밋 목록 표시
④ 롤백할 버전 선택 → [롤백 적용]
   → git reset --hard <커밋해시> → PM2 재시작
```

> ⚠️ 업데이트 중 30~60초간 서비스 중단됩니다. 업무 외 시간 권장.

### 4-7. 위험성평가 관리

**경로**: 안전점검 → **위험성평가**

| 항목 | 설명 | 사용 시기 |
|------|------|----------|
| **정기 위험성평가** | 분기·반기·연간 단위 정기 평가 등록·승인 | 분기 1회 이상 |
| **수시 위험성평가** | 특수 작업·사고 발생 시 즉시 평가 | 위험 작업 전 |
| **분류별 항목 관리** | 위험 분류·항목 사전 등록 (평가 시 자동 불러오기) | 초기 설정 시 |
| **안전설정 관리** | 점검 체크리스트 항목 커스터마이징 | 초기 설정 시 |

**위험성평가 등록 흐름:**
```
① 평가 유형 선택 (정기 / 수시)
② [+ 평가 추가] → 평가일·현장·작업 선택
③ 분류별 항목 자동 로드 → 위험등급 설정 (상/중/하)
④ 개선대책 입력
⑤ [저장] → 감독자/관리자 검토 후 [승인]
⑥ 승인된 평가 → 서명 요청 발송 가능
```

> 근로자는 위험성평가 **조회만** 가능하며, 등록·수정·삭제는 감독자 이상만 가능합니다.

**교육 등록 및 서명 수집 흐름:**

```
④ 대상자: 앱에서 내용 확인 → 전자서명 입력 → [서명 완료]
⑤ 교육현황통계에서 서명 완료 여부 실시간 확인
```

## 5. 감독자 (안전관리자 · 공무 · 현장대리인) 가이드

> **대상**: DB 권한 `supervisor` — 안전관리자 · 공무 · 현장대리인
> **특징**: 관리자 메뉴 대부분 사용 가능 / **계정관리**, **단가 관리**는 사용 불가

### 5-1. 관리자와의 차이

| 기능 | 관리자 (admin) | 감독자 (supervisor) |
|------|--------|--------|
| 전체 메뉴 5그룹 접근 | ✅ | ✅ |
| 시스템 설정 8탭 | ✅ | ✅ |
| **계정관리 (사용자 등록·삭제)** | ✅ | ❌ |
| **단가 관리** | ✅ | ❌ |
| 공량내역 금액 열 표시 | ✅ | ✅ |
| 업무중지사용자 조회 | ✅ | ✅ |
| 현장팀관리 | ✅ | ✅ |
| 위험성평가 등록·수정 | ✅ | ✅ |
| 안전교육 등록 | ✅ | ✅ |

> 계정 생성·삭제·역할 변경은 관리자(admin)에게 요청하세요.

### 5-2. 감독자 역할별 실무 차이

3종의 감독자 역할은 기술적으로 동일한 권한을 가지지만 실무 담당 영역이 다릅니다:

| 역할 | 주요 담당 실무 |
|------|--------------|
| **안전관리자** | 안전점검 주도 · 위험성평가 · 위험신고 처리 · 안전교육 운영 |
| **공무** | 공사 등록·관리 · 작업 배정 · 물량통계 · 공량내역 |
| **현장대리인** | 전반적인 현장 운영 · 작업현황 모니터링 · 통계 보고 |

### 5-3. 현장점검 실시

**경로**: 안전점검 → **현장점검**

```
① [+ 점검 추가] 버튼 클릭

② 점검 정보 입력:
   - 점검일시: 오늘 날짜 자동 입력 (수정 가능)
   - 공사/현장 선택
   - 점검 유형: 정기점검 / 불시점검 / 특별점검

③ 점검 항목 체크 (안전설정에서 미리 등록된 체크리스트 자동 로드)
   - 적합 ✅ / 부적합 ❌ 선택

④ 부적합 항목 발견 시:
   - [사진 첨부] → 현장 사진 촬영 또는 갤러리 선택
   - [조치 내용] 입력
   - 개선 기한 설정

⑤ [저장] → 점검 완료 처리

⑥ 개선 조치 완료 확인 후 [완료 처리]
```

### 5-4. 위험신고 처리

**경로**: 안전점검 → **위험신고**

근로자가 신고한 위험 내용을 확인하고 조치합니다.

```
① 신고 목록에서 미처리 항목 확인 (빨간색 배지 = 미처리 건수)

② 신고 내용 클릭 → 상세 보기:
   - 신고자 정보
   - 위험 유형 (추락 위험 / 감전 위험 / 화재 위험 / 기타)
   - 위험 내용 텍스트
   - 첨부 사진 (최대 5장)
   - GPS 위치 (지도 표시)

③ [조치 내용 입력] → 현장 조치 완료 후 내용 기록

④ [처리 완료] 버튼 클릭 → 신고자에게 처리 완료 알림 발송

⑤ 처리 완료된 신고는 [완료] 탭으로 이동
```

### 5-5. 서명 요청 발송 및 관리

**경로**: 안전관리 → **서명요청**

```
① [+ 서명 요청 추가]

② 요청 유형 선택:
   - 안전교육 서명
   - 위험성평가 서명
   - 작업지시 확인 서명

③ 대상자 선택:
   - 개인 검색 후 선택
   - 현장팀 단위로 일괄 선택

④ [발송] → 대상자 앱에 FCM 알림 + 앱 내 배지 발송

⑤ 서명 현황 탭에서 실시간 확인:
   ┌────────────────────────────────┐
   │ 이름  │ 상태   │ 서명일시       │
   │ 홍길동 │ ✅완료  │ 2026-07-25 14:32 │
   │ 김철수 │ ⏳대기  │ —              │
   └────────────────────────────────┘

⑥ 미서명자 → [재발송] 버튼으로 다시 알림
```

### 5-6. 작업현황 모니터링

**경로**: 현장작업 → **작업현황** (대시보드)

```
├─────────────────────────────────────────┤
│  작업 목록 (최근 순)                       │
│  ┌────────────────────────────────────┐  │

└─────────────────────────────────────────┘
```

### 5-7. 작업 관리 (등록 · 수정 · 상태 변경)

**경로**: 현장작업 → **작업관리**

**작업 등록:**
```
① [+ 작업 추가]
② 작업명 · 공사 선택 · 작업일 · 담당 근로자 배정
③ 작업 유형 선택 (케이블포설 · 접속 · 기타 등)
④ [저장] → 근로자 앱에 즉시 배정 알림
```

**작업 상태 흐름:**
```
[대기] → [작업 시작] → [진행중] → [작업 완료] → [완료]
                                  ↑ 근로자가 직접 상태 변경
         ↑ 감독자/관리자도 강제 변경 가능
```

**작업 복사 기능** (반복 작업에 유용):
```
작업 상세 → [전체 진행단계 복사] 버튼
→ 기존 작업의 모든 정보를 복사하여 새 작업으로 생성
→ 날짜·담당자만 변경 후 저장
```

### 5-8. 통계 및 보고서

**경로**: 공사현황 그룹 내 통계 메뉴

| 통계 메뉴 | 내용 | 주요 활용 |
|-----------|------|----------|

| **작업통계** | 작업 건수 · 유형별 분류 · 일별 추이 | 일일/주간 보고 |
| **물량통계** | 케이블 포설 물량 집계 | 공정 물량 보고 |
| **공량내역** | 작업별 공량 · 금액 (단가 설정 시 자동 계산) | 원가 관리 |
| **광케이블 현황** | 케이블 종류별 포설 현황 | 자재 관리 |

**작업일보 작성:**
```
경로: 공사현황 → [작업일보 작성]

③ 특이사항 · 내일 계획 입력
④ [저장] 또는 [PDF 출력]
```

## 6. 근로자 가이드

> **대상**: DB 권한 `worker` — 현장 근로자 전원
> **특징**: 내 작업 / 위험신고 / 서명요청 / 내 계정만 접근 가능

### 6-1. 근로자 화면 구성

로그인 후 **나의작업현황** 페이지가 자동으로 표시됩니다.

```
왼쪽 레일 (3그룹):
┌───────────────┐
│ 🔵 내 작업    │  → 내 작업 · 작업일보 · 나의작업현황
│ 🔴 안전       │  → 위험신고 · 서명요청
│ 🟡 내 정보    │  → 내 계정
└───────────────┘

하단 탭바 (모바일):
┌──────────┬──────────┬──────────┐
│  내 작업  │  위험신고 │  내 정보  │
│  📋       │  ⚠️       │  👤       │
└──────────┴──────────┴──────────┘
```

### 6-2. 내 작업 확인

**경로**: 내 작업 → **내 작업** 또는 하단 탭 [내 작업]

```
① 오늘 배정된 작업 목록 확인

② 작업 카드를 눌러 상세 보기:
   ┌─────────────────────────────┐
   │  작업명: OO케이블 포설       │
   │  공사명: OO공사               │
   │  현장 주소: OO시 OO동         │
   │  작업 유형: 케이블포설         │
   │  담당 감독자: 홍길동           │
   │  현재 상태: [대기]            │
   │  연계 사진: (감독자 첨부)      │
   └─────────────────────────────┘

③ [공사요청번호 클릭] → 관련 공사 상세 정보 바로 이동
```

### 6-3. 작업 상태 변경 (근로자 직접 수행)

근로자는 자신의 작업 상태를 직접 변경할 수 있습니다.

| 버튼 | 설명 | 조건 |
|------|------|------|
| **[작업 시작]** | 작업 현장 도착 후 시작 신고 | 상태: 대기 |
| **[작업 완료]** | 작업 종료 후 완료 신고 | 상태: 진행중 |
| **[작업 재개]** | 중단 후 재시작 | 상태: 일시중단 |

**작업 시작 흐름:**
```
① 내 작업 카드 → [작업 시작] 버튼 클릭
② GPS 위치 자동 수집 (위치 권한 필요)
   → GPS 주소 자동 표시 (카카오 API 연동 시)
③ 상태 → "진행중"으로 변경
④ 감독자에게 알림 발송
```

> ⚠️ **GPS 위치 확인**: 작업 시작/완료 시 GPS 위치가 자동으로 기록됩니다.
> 위치 권한을 허용해야 정상 등록됩니다.

### 6-4. 작업일보 작성

**경로**: 내 작업 → **작업일보 작성**

```
① 작성일 확인 (기본: 오늘)

② 오늘 완료한 작업이 자동으로 목록에 표시됨

③ 작업별 정보 입력:
   - 실제 투입 시간 (시간/분)
   - 작업 내용 특이사항
   - 진행률 (%)

④ [저장] 버튼 클릭

⑤ 담당 감독자에게 자동 제출됨
```

### 6-5. 나의 작업 현황

**경로**: 내 작업 → **나의작업현황** (로그인 후 첫 화면)

```
표시 정보:
- 이번 달 작업 건수 · 완료율
- 최근 작업 이력 (최근 10건)
- 안전교육 이수 현황 (완료/미완료)
- 서명 요청 미처리 건수
```

### 6-6. 위험신고

**경로**: 안전 → **위험신고** 또는 하단 탭 [위험신고]

현장에서 위험한 상황을 발견했을 때 즉시 신고합니다.

```
① [+ 신고하기] 버튼

② 위험 정보 입력:
   - 위험 유형 선택:
     • 추락 위험
     • 감전 위험
     • 화재 위험
     • 기타 위험
   - 위험 내용 텍스트 입력 (구체적으로 작성)
   - [사진 추가] → 현장 사진 첨부 (최대 5장)
   - GPS 위치 자동 입력 (수동 수정 가능)

③ [신고] 버튼 클릭

④ 담당 감독자에게 FCM 알림 즉시 발송됨

⑤ 처리 결과 확인:
   내 신고 목록 → 처리상태 확인 (미처리/처리완료)
```

> 🚨 **긴급 상황**에서는 신고와 함께 **112 / 119**에 즉시 연락하세요.

### 6-7. 서명요청 처리

**경로**: 안전 → **서명요청** 또는 🔔 알림 배지 클릭

감독자/관리자가 보낸 서명 요청을 처리합니다.

```
① 서명 요청 목록 확인 (미처리 건수: 🔔 빨간 배지)

② 요청 항목 클릭 → 내용 확인:
   - 요청 유형 표시 (안전교육 / 위험성평가 / 작업지시)
   - 교육 내용 전체 텍스트 표시
   - 발송자 · 발송일시

③ 내용을 읽고 이해한 후 [서명] 버튼 클릭

④ 서명 패드에 손가락으로 서명 입력
   (손가락을 화면에 대고 이름을 그리듯 서명)

⑤ [서명 완료] → 담당자에게 자동 전송

⑥ 완료된 서명은 [완료] 탭에서 확인 가능
```

> ⚠️ **중요**: 내용을 충분히 읽고 이해한 후 서명하세요. 서명 후 취소가 불가합니다.

## 7. LGU+ 사용자 가이드

> **대상**: DB 권한 `lgu_plus` — LGU+ 관련 외부 사용자
> **특징**: 관리자가 "LGU+ 권한 설정" 탭에서 허용한 메뉴만 접근 가능

### 7-1. LGU+ 권한의 특징

LGU+ 사용자는 별도 메뉴 그룹(`lguGroups`)을 사용합니다.

```
접근 가능 메뉴:
→ 시스템설정 → LGU+ 권한 설정 탭에서 관리자가 지정한 메뉴만 표시
→ 기본값: 모든 메뉴 비허용 (관리자가 명시적으로 허용해야 함)

접근 불가 메뉴:
→ 계정관리 (항상 제한)
→ 단가 관리 (항상 제한)
→ 허용되지 않은 메뉴 전체
```

### 7-2. LGU+ 사용자 로그인

로그인 방법은 다른 사용자와 동일합니다:
1. 아이디(전화번호) + 비밀번호 입력
2. 관리자에게 허용된 메뉴만 표시됨
3. 허용 메뉴 변경 시 재로그인 후 반영

### 7-3. LGU+ 접근 불가 시

"권한이 없습니다" 메시지가 표시되면 담당 관리자에게 LGU+ 권한 설정 변경을 요청하세요.

## 8. 공통 — 자주 묻는 질문 (FAQ)

### Q1. 로그인이 안 됩니다

| 증상 | 원인 | 해결 방법 |
|------|------|----------|
| "아이디 또는 비밀번호가 틀렸습니다" | 비밀번호 오류 | 관리자에게 비밀번호 초기화 요청 |
| "계정이 존재하지 않습니다" | 미등록 계정 | 관리자에게 계정 등록 요청 |
| "업무 중지 계정입니다" | 계정 정지 상태 | 관리자에게 계정 복구 요청 |
| 접속 자체가 안 됨 | 서버/네트워크 문제 | 관리자에게 서버 상태 확인 요청 |
| 인증서 경고 후 연결 거부 | 브라우저 보안 설정 | "고급 → 계속 진행" 클릭 |

### Q2. 화면이 흰색으로 멈춥니다

1. 화면을 아래로 당겨 **새로고침** (Pull-to-refresh)
2. 앱을 완전히 종료 후 재실행
3. 브라우저라면 `F5` 또는 주소창에서 새로고침
4. 증상 지속 시 관리자에게 서버 재시작 요청

### Q3. GPS 위치가 잘못 표시됩니다

1. 기기 설정 → **위치 권한** → SafetyNOTE 앱에 "항상 허용" 설정
2. GPS 신호가 약한 실내에서는 오차가 발생할 수 있습니다
3. 위치가 크게 틀렸다면 **수동으로 주소를 입력**하세요
4. 카카오 API 미설정 시 GPS 좌표만 표시됨 → 관리자에게 API 설정 요청

### Q4. 사진이 업로드되지 않습니다

1. 기기 설정 → **저장소 권한** 또는 **사진 접근 권한** 허용
2. 사진 파일 크기 확인 (10MB 이하 권장)
3. 모바일 데이터 또는 Wi-Fi 연결 상태 확인
4. 서버 업로드 경로 여유 공간 부족 시 → 관리자에게 파일 설정 탭 확인 요청

### Q5. 서명 요청 알림이 오지 않습니다

1. 기기 설정 → **알림 권한** → SafetyNOTE 허용
2. FCM 알림은 WiFi 또는 LTE 연결이 필요합니다
3. 앱을 열면 미처리 서명 요청이 목록에 표시됩니다 (알림 없이도 확인 가능)
4. 관리자: 시스템설정 → 푸시 알림 발송 탭에서 테스트 발송으로 확인

### Q6. 비밀번호를 잊어버렸습니다

직접 변경이 불가합니다. **관리자(CEO 또는 시스템관리자)에게 비밀번호 초기화를 요청**하세요.

```
관리자 처리 방법:
관리/설정 → 사용자관리 → 계정관리
→ 해당 계정 선택 → [비밀번호 초기화]
→ 임시 비밀번호 생성 → 사용자에게 전달
```

### Q7. 앱 버전을 확인하고 싶습니다

- **로그인 화면** 하단에 현재 APK 버전 표시
- **시스템 설정 → 정보 탭**: 서버 버전 + APK 버전 동시 확인 _(관리자/감독자만)_

### Q8. 작업이 내 목록에 안 보입니다

1. 관리자/감독자가 아직 배정하지 않은 상태일 수 있습니다 → 담당 감독자에게 확인
2. 날짜 필터 확인 — 오늘 날짜 기준으로 표시됩니다
3. 앱 새로고침 후 재확인
4. 계정 역할이 근로자로 설정되어 있는지 관리자에게 확인

### Q9. 서명 요청이 완료됐는데 감독자가 못 보고 있습니다

1. 앱에서 서명 완료 탭에서 서명 날짜/시간 확인
2. 감독자에게 서명 현황 탭 새로고침 안내
3. 서명 완료 후 감독자 앱에 알림이 자동 발송됩니다

### Q10. 푸시 알림은 오는데 앱을 열면 내용이 없습니다

1. 앱을 완전히 종료 후 재실행
2. 로그아웃 후 재로그인
3. 알림 내용이 이미 처리된 경우 [완료] 탭에서 확인
