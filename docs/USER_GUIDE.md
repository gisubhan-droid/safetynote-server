## 1. 권한(역할) 구조 한눈에 보기

SafetyNOTE는 **3단계 권한 구조**로 운영됩니다.

| 화면 표시 역할 | DB 권한 그룹 | 사용 가능 범위 |
|---------------|-------------|----------------|
| **CEO** | 관리자 (admin) | 전체 메뉴 + 시스템 설정 + 계정관리 + 단가 관리 |
| **시스템관리자** | 관리자 (admin) | CEO와 동일 + 계정관리 전담 |
| **안전관리자** | 감독자 (supervisor) | 전체 메뉴 + 시스템 설정 (계정·단가 제외) |
| **공무** | 감독자 (supervisor) | 안전관리자와 동일 |
| **현장대리인** | 감독자 (supervisor) | 안전관리자와 동일 |
| **근로자** | 근로자 (worker) | 내 작업 / 위험신고 / 서명요청 / 내 계정만 |
| **LGU+** | lgu_plus | 별도 권한 설정 기반 제한 메뉴 |

## 2. 공통 — 앱 설치 및 첫 로그인

### 2-1. APK 설치 (Android)

1. 로그인 화면 하단 **"APK 설치 파일 다운로드"** 버튼을 누릅니다.  
   _(버튼이 없으면 관리자에게 APK URL 등록을 요청하세요)_
2. 다운로드된 `.apk` 파일을 실행합니다.
3. **"알 수 없는 출처 앱 허용"** 메시지가 나오면 **허용**을 누릅니다.
4. 설치 완료 후 SafetyNOTE 아이콘을 탭합니다.

> **버전 확인**: 앱 실행 후 로그인 화면 하단에 현재 APK 버전이 표시됩니다.

### 2-2. 브라우저 접속 (PC · 태블릿)

| 환경 | 접속 방법 |
|------|----------|
| 사내 네트워크 | `https://NAS주소:3443` |
| 외부 (DDNS) | `https://도메인:3443` |
| 모바일 브라우저 | 위와 동일 주소 입력 |

> ⚠️ **주의**: 접속 시 인증서 경고가 나오면 **"계속 진행"** 또는 **"고급 → 접속"**을 누르세요.  
> (자체서명 인증서 환경인 경우 정상입니다)

### 2-3. 첫 로그인

1. 관리자에게 받은 **아이디(전화번호 형식)** 와 **임시 비밀번호**를 입력합니다.
2. **로그인** 버튼을 누릅니다.
3. 첫 로그인 후 즉시 **내 계정 → 비밀번호 변경**을 진행하세요.

### 2-4. 로그인 화면 구성

```
┌─────────────────────────────────┐
│         SafetyNOTE              │
│                                 │
│   [아이디 입력 (전화번호)]       │
│   [비밀번호 입력]                │
│                                 │
│         [로그인]                 │
│                                 │
│   APK 설치 파일 다운로드 ↓       │  ← 관리자가 APK URL 설정 시 표시
└─────────────────────────────────┘
```

## 3. 공통 — 화면 구성 및 내비게이션

### 3-1. 전체 화면 구조

```
┌──────────────────────────────────────────────────────┐
│  상단 헤더: 현재 페이지 제목 + 알림 아이콘             │
├──────┬───────────────────────────────────────────────┤
│      │                                               │
│ 왼쪽 │              메인 콘텐츠 영역                  │
│ 레일 │                                               │
│(아이 │                                               │
│콘 모 │                                               │
│음)   │                                               │
│      │                                               │
├──────┴───────────────────────────────────────────────┤
│   하단 탭바 (주요 메뉴 바로가기, 모바일 전용)          │
└──────────────────────────────────────────────────────┘
```

### 3-2. 왼쪽 레일 (아이콘 모음)

- 화면 왼쪽에 **그룹 아이콘**이 세로로 나열됩니다.
- 아이콘을 누르면 **플라이아웃 메뉴**(오른쪽으로 펼쳐짐)가 열립니다.
- 플라이아웃에서 원하는 메뉴 항목을 누르면 해당 페이지로 이동합니다.

### 3-3. 권한별 메뉴 그룹 비교

**관리자 · 감독자** (5개 그룹):

| 그룹 아이콘 | 그룹명 | 주요 메뉴 |
|------------|--------|----------|
| 🔵 현장 헬멧 | **현장작업** | 작업현황 · 작업관리 · 공사현황 · 현장위치 지도 |
| 🔴 방패 | **안전점검** | 현장점검 · 위험신고 · 위험성평가 (정기/수시/항목관리/안전설정) |
| 🟣 체크보드 | **안전관리** | 안전현황 통계 · 안전교육 (5종) · 서명요청 |
| 🟢 차트 | **공사현황** | 공사통계 · 작업통계 · 물량통계 · 작업일보 · 공량내역 · 광케이블 현황 |
| 🟡 톱니바퀴 | **관리/설정** | 사용자관리 · 내 계정 · 시스템 설정 · 법령안내 관리 |

**근로자** (3개 그룹):

| 그룹 아이콘 | 그룹명 | 주요 메뉴 |
|------------|--------|----------|
| 🔵 체크리스트 | **내 작업** | 내 작업 · 작업일보 작성 · 나의작업현황 |
| 🔴 방패 | **안전** | 위험신고 · 서명요청 |
| 🟡 톱니바퀴 | **내 정보** | 내 계정 |

### 3-4. 알림 (서명요청)

- 상단 헤더의 🔔 **알림 아이콘**에 빨간 배지가 뜨면 서명 요청이 있습니다.
- 알림 아이콘을 누르면 **서명요청** 페이지로 바로 이동합니다.

## 4. 관리자 (CEO · 시스템관리자) 전용 가이드

> **대상**: DB 권한 `admin` — CEO · 시스템관리자  
> **특징**: 전체 메뉴 접근 가능 + 시스템 설정 8개 탭 전체 + 계정관리 + 단가 관리

### 4-1. 사용자 계정 관리

**경로**: 관리/설정 → 사용자관리 → **계정관리** _(시스템관리자만 보임)_

| 작업 | 방법 |
|------|------|
| 신규 계정 등록 | [+ 사용자 추가] 버튼 → 이름·전화번호·역할·직위 입력 → 저장 |
| 비밀번호 초기화 | 해당 계정 행 선택 → [비밀번호 초기화] → 임시 비밀번호 전달 |
| 계정 정지 | 해당 계정 행 → [업무 중지] → 중지 사유 입력 |
| 중지 계정 복구 | 사용자관리 → [업무중지사용자] 탭 → [업무 복구] |
| 역할 변경 | 계정 편집 모달 → 역할 드롭다운에서 변경 |

**역할 드롭다운 옵션:**

```
근로자 / 안전관리자 / 공무 / 현장대리인 / CEO / LGU+ / 시스템관리자
```

### 4-2. 현장팀 관리

**경로**: 관리/설정 → 사용자관리 → **현장팀관리**

- **팀 생성**: [+ 팀 추가] → 팀명 입력 → 팀원 배정
- **팀원 추가**: 팀 행 선택 → [팀원 추가] → 근로자 검색 후 선택
- **팀 해산**: 팀 행 → [삭제] _(팀원 전원 자동 해제됨)_

### 4-3. 공사 · 작업 전체 관리

**경로**: 현장작업 → **공사현황**

| 상태 흐름 | 설명 |
|-----------|------|
| 등록 | 공사 정보 입력 (공사명 · 공사요청번호 · 현장주소 등) |
| 진행중 | 작업 배정 후 자동 전환 |
| 완료 | 모든 작업 완료 시 수동 완료 처리 |

**작업 배정 방법:**
1. 공사현황에서 해당 공사 선택
2. **[작업 추가]** 버튼 → 작업명·날짜·근로자 배정
3. 근로자 앱에 즉시 반영됨

### 4-4. 단가 관리 _(시스템관리자 포함 admin 전용)_

**경로**: 공사현황 → **단가 관리**

- 작업 유형별 단가 등록 및 수정
- 공량내역 / 물량통계의 금액 계산 기준이 됨
- 근로자에게는 금액이 표시되지 않음 (admin/supervisor에게만 노출)

### 4-5. 시스템 설정 (8개 탭)

**경로**: 관리/설정 → **시스템 설정**

| 탭 | 주요 기능 | 사용 빈도 |
|----|----------|----------|
| 📢 **푸시 알림 발송** | 전체·그룹·개인 푸시 알림 즉시 발송 | 수시 |
| 📁 **파일 설정** | 서버 업로드 파일 관리, 저장 경로 설정 | 간헐적 |
| 📍 **GPS 주소 변환** | 카카오 API 키 설정 (현장 주소 자동 변환용) | 초기 1회 |
| 🤖 **APK 배포 관리** | APK 다운로드 URL 등록 / 파일 직접 업로드 | APK 업데이트 시 |
| 🔄 **서버 업데이트** | 원클릭 서버 최신 버전 업데이트 + 롤백 | 업데이트 시 |
| 👥 **그룹별 권한 설정** | 감독자 / 근로자별 메뉴 표시 여부 설정 | 초기 설정 시 |
| 🏢 **LGU+ 권한 설정** | LGU+ 역할 사용자의 메뉴 표시 여부 설정 | 초기 설정 시 |
| ℹ️ **정보** | 서버 버전 · APK 버전 · 시스템 정보 확인 | 수시 |

#### 4-5-1. APK 배포 관리 탭 사용법

```
① [APK URL] 입력창에 다운로드 주소 붙여넣기
   또는
① [파일 선택] → APK 파일 선택 → [업로드] 버튼 (서버에 직접 저장)

② [APK 설정 저장] 버튼 클릭

③ 로그인 화면에 "APK 설치 파일 다운로드" 버튼 자동 표시 확인
```

#### 4-5-2. 서버 업데이트 탭 사용법

```
① [현재 버전 확인] — 현재 서버 버전과 GitHub 최신 버전 표시

② 업데이트 버전이 있으면 [업데이트 적용] 버튼 활성화

③ [업데이트 적용] 클릭 → 실시간 로그 출력 (약 1~3분 소요)

④ 완료 메시지 확인 → 자동 재시작됨

⑤ 롤백 필요 시: [이전 버전 목록] → 원하는 버전 선택 → [롤백 적용]
```

> ⚠️ **업데이트 중 주의**: 업데이트 적용 중에는 다른 사용자의 접속이 약 30~60초 끊길 수 있습니다.

### 4-6. 법령안내 관리

**경로**: 관리/설정 → **법령안내 관리**

- 산업안전보건법 등 법령 조항 등록 및 수정
- 근로자 서명 화면에 법령 내용이 표시됨
- **항목 편집**: 항목 선택 → 내용 수정 → [저장]

### 4-7. 위험성평가 관리

**경로**: 안전점검 → **위험성평가**

| 항목 | 설명 |
|------|------|
| **정기 위험성평가** | 분기·반기·연간 단위 정기 평가 등록·승인 |
| **수시 위험성평가** | 특수 작업·사고 발생 시 즉시 평가 |
| **분류별 항목 관리** | 위험 분류·항목 사전 등록 (평가 시 자동 불러오기) |
| **안전설정 관리** | 점검 체크리스트 항목 커스터마이징 |

> 근로자는 위험성평가 **조회만** 가능하며, 등록·수정·삭제는 감독자 이상만 가능합니다.

### 4-8. 안전교육 관리

**경로**: 안전관리 → **안전교육**

| 교육 유형 | 설명 | 주기 |
|-----------|------|------|
| 정기안전교육 | 전체 근로자 대상 법정 교육 | 분기 1회 이상 |
| 채용시안전교육 | 신규 채용 근로자 입교 교육 | 채용 즉시 |
| 작업내용변경시교육 | 작업 내용 변경 시 추가 교육 | 변경 시 |
| 특별안전교육 | 위험 작업 전 집중 교육 | 작업 전 |
| 관리감독자교육 | 관리자·감독자 전문 교육 | 연 1회 이상 |

**교육 등록 방법:**
1. 교육 유형 선택 → **[+ 교육 추가]**
2. 교육일시·장소·내용·대상자 선택
3. 대상자별 **서명 요청** 발송 (모바일 서명 수집)
4. 서명 완료 여부 교육현황통계에서 확인

## 5. 감독자 (안전관리자 · 공무 · 현장대리인) 가이드

> **대상**: DB 권한 `supervisor` — 안전관리자 · 공무 · 현장대리인  
> **특징**: 관리자 메뉴 대부분 사용 가능 / **계정관리**, **단가 관리**는 사용 불가

### 5-1. 관리자와의 차이

| 기능 | 관리자 | 감독자 |
|------|--------|--------|
| 전체 메뉴 접근 | ✅ | ✅ |
| 시스템 설정 | ✅ (8탭 전체) | ✅ (8탭 전체) |
| **계정관리 (사용자 등록·삭제)** | ✅ | ❌ |
| **단가 관리** | ✅ | ❌ |
| 업무중사용자 조회 | ✅ | ✅ |
| 현장팀관리 | ✅ | ✅ |

> 시스템 설정은 관리자와 동일하게 접근 가능하지만, **계정 생성·삭제는 관리자(admin)에게 요청**하세요.

### 5-2. 현장점검 실시

**경로**: 안전점검 → **현장점검**

```
① [+ 점검 추가] 버튼 클릭

② 점검 정보 입력:
   - 점검일시: 오늘 날짜 자동 입력 (수정 가능)
   - 공사/현장 선택
   - 점검 유형: 정기점검 / 불시점검 / 특별점검

③ 점검 항목 체크 (미리 등록된 체크리스트 자동 로드)

④ 부적합 항목 발견 시:
   - [사진 첨부] → 현장 사진 촬영 또는 갤러리 선택
   - [조치 내용] 입력
```

## 6. 근로자 가이드

> **대상**: DB 권한 `worker` — 현장 근로자 전원  
> **특징**: 내 작업 / 위험신고 / 서명요청 / 내 계정만 접근 가능

### 6-1. 근로자 화면 구성

로그인 후 **나의작업현황** 페이지가 자동으로 표시됩니다.

```
하단 탭바 구성:
┌──────────┬──────────┬──────────┐
│  내 작업  │  위험신고 │  내 정보  │
│  📋       │  ⚠️       │  👤       │
└──────────┴──────────┴──────────┘
```

### 6-2. 내 작업 확인

**경로**: 내 작업 → **내 작업** 또는 하단 탭 [내 작업]

```
① 오늘 배정된 작업 목록 확인

② 작업 카드를 눌러 상세 보기:
   - 작업명 · 공사명 · 현장 주소
   - 작업 유형 · 담당자 정보
   - 연계 작업 사진 (감독자가 첨부한 사진)

③ [공사요청번호 클릭] → 관련 공사 상세 정보 바로 이동
```

### 6-3. 작업 상태 변경 (근로자 직접 수행)

근로자는 자신의 작업 상태를 직접 변경할 수 있습니다.

| 버튼 | 설명 | 조건 |
|------|------|------|
| **[작업 시작]** | 작업 현장 도착 후 시작 신고 | 상태: 대기 |
| **[작업 완료]** | 작업 종료 후 완료 신고 | 상태: 진행중 |
| **[작업 재개]** | 중단 후 재시작 | 상태: 일시중단 |

> ⚠️ **GPS 위치 확인**: 작업 시작/완료 시 GPS 위치가 자동으로 기록됩니다.  
> 위치 권한을 허용해야 정상 등록됩니다.

**경로**: 안전 → **위험신고** 또는 하단 탭 [위험신고]

```
② 위험 정보 입력:
   - 위험 유형 선택 (추락 위험 / 감전 위험 / 화재 위험 / 기타)
   - 위험 내용 텍스트 입력
   - [사진 추가] → 현장 사진 첨부 (최대 5장)
   - GPS 위치 자동 입력 (수동 수정 가능)

③ [신고] 버튼 클릭

④ 감독자에게 즉시 알림 발송됨

⑤ 처리 결과는 내 신고 목록에서 확인 가능
```

**경로**: 안전 → **서명요청** 또는 🔔 알림 배지 클릭

```

② 요청 항목 클릭 → 내용 확인:
   - 안전교육 내용 / 위험성평가 내용 / 작업지시 내용

③ 내용을 읽고 이해한 후 [서명] 버튼 클릭

④ 서명 패드에 손가락으로 서명 입력

⑤ [서명 완료] → 감독자에게 자동 전송

⑥ 완료된 서명은 [완료] 탭에서 확인
```

> ⚠️ **중요**: 내용을 충분히 읽고 이해한 후 서명하세요. 서명 후 취소가 불가합니다.

## 7. 공통 — 자주 묻는 질문 (FAQ)

### Q1. 로그인이 안 됩니다

| 증상 | 원인 | 해결 방법 |
|------|------|----------|
| "아이디 또는 비밀번호가 틀렸습니다" | 비밀번호 오류 | 관리자에게 비밀번호 초기화 요청 |
| "계정이 존재하지 않습니다" | 미등록 계정 | 관리자에게 계정 등록 요청 |
| "업무 중지 계정입니다" | 계정 정지 상태 | 관리자에게 계정 복구 요청 |
| 접속 자체가 안 됨 | 서버/네트워크 문제 | 관리자에게 서버 상태 확인 요청 |

### Q2. 화면이 흰색으로 멈춥니다

1. 화면을 아래로 당겨 **새로고침** (Pull-to-refresh)
2. 앱을 완전히 종료 후 재실행
3. 브라우저라면 `F5` 또는 주소창에서 새로고침

### Q3. GPS 위치가 잘못 표시됩니다

1. 기기 설정 → **위치 권한** → SafetyNOTE 앱에 "항상 허용" 설정
2. GPS 신호가 약한 실내에서는 오차가 발생할 수 있습니다
3. 위치가 크게 틀렸다면 수동으로 주소를 입력하세요

### Q4. 사진이 업로드되지 않습니다

1. 기기 설정 → **저장소 권한** 또는 **사진 접근 권한** 허용
2. 사진 파일 크기 확인 (10MB 이하 권장)
3. 모바일 데이터 또는 Wi-Fi 연결 상태 확인

### Q5. 서명 요청 알림이 오지 않습니다

1. 기기 설정 → **알림 권한** → SafetyNOTE 허용
2. FCM 알림은 WiFi 또는 LTE 연결이 필요합니다
3. 앱을 열면 미처리 서명 요청이 목록에 표시됩니다

### Q6. 비밀번호를 잊어버렸습니다

직접 변경이 불가합니다. **관리자(CEO 또는 시스템관리자)에게 비밀번호 초기화를 요청**하세요.

### Q7. 앱 버전을 확인하고 싶습니다

- **로그인 화면** 하단에 현재 APK 버전 표시
- **시스템 설정 → 정보 탭**: 서버 버전 + APK 버전 동시 확인 _(관리자/감독자만)_

### Q8. 작업이 내 목록에 안 보입니다

1. 관리자/감독자가 아직 배정하지 않은 상태일 수 있습니다 → 담당 감독자에게 확인
2. 날짜 필터 확인 — 오늘 날짜 기준으로 표시됩니다
3. 앱 새로고침 후 재확인
